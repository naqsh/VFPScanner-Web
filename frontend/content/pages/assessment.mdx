## What you receive

A written report, walked through with you on a call:

- **Module-by-module risk**: which parts of the application are hard to move and why, from the scan plus a human review.
- **Redesign list**: every place that builds or runs code at run time (macro substitution, EVALUATE, forms built in code), Windows API calls and COM components, with what each needs.
- **Data migration map**: every table and field with its proposed SQL Server type, data issues to fix first, and code page notes.
- **Clean-up list**: duplicates, old copies and files outside any project that you may not need to migrate, to confirm with your team.
- **Compliance impact**: where invoice, VAT, 1099, payroll and EDI data live, and what the e-invoicing or IRIS deadlines mean for them.
- **Phased plan with effort ranges**: what to move first, what can run side by side, and the options (bridge first, full migration, or both).

## How it works

1. **Kick-off call (about 45 minutes).** You explain how the application is used and what matters most.
2. **You run the scan** and share the report. If you agree, you also give read access to the source code. We can work under your NDA.
3. **Review (5 to 10 working days)**, depending on size. Questions come to you in writing, so your team is not blocked.
4. **Results call.** We go through the report together. You keep the report, whatever you decide next.

If you go ahead with a migration, the assessment fee is credited against it.
