## Who you work with

I'm Kashif, a senior .NET engineer with more than 15 years of experience building software for fintech, banking, ERP, legal tech and shipping. My specialty is moving Visual FoxPro applications to .NET and SQL Server.

When you work with VFP Migration Scanner, you work with me directly: on the scan, the assessment and the migration.

## Why the scanner exists

Every FoxPro migration starts with the same questions. How big is it really? Which parts are hard? What can we leave behind? Those answers are in the code and the data, so I built a tool that reads them.

The scanner reads FoxPro's own file formats, finds the patterns that make migration hard, and profiles the data for SQL Server. It runs on your PC, so you can see the facts before you talk to anyone.

## How I work

- **Facts first.** Every estimate starts from what the scan measured.
- **No surprises.** Risks are written down before work starts, not discovered halfway.
- **Old and new side by side.** Nothing is switched off until the new version gives the same results.
